Email Template Variables

Your EmailJS template should include these variables:

{{confidence}}       — Confidence percentage
{{timestamp}}        — Detection date & time
{{source}}           — Camera/video source name
{{location}}         — Detection location info
{{snapshot_url}}     — Link to snapshot image
{{to_email}}         — Recipient email
{{system_name}}      — "CrimeVision AI"
